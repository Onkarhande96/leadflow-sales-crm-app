## 📌 Executive Overview
Small businesses, marketing agencies, and freelancers lose up to **70% of inbound prospective revenue** simply due to slow follow-up times, disjointed spreadsheets, and a lack of visual pipeline clarity.

**LeadFlow CRM** solves this by providing:
1. **Real-time Pipeline Metrics**: Instant tracking of Total Deals, Pipeline Value (₹), Closed Won Revenue, Conversion Rates, and Average Deal Size.
2. **Interactive Visual Analytics**: Interactive Plotly charts for Funnel Stage distribution, Service Breakdown (Donut chart), and Lead Acquisition Channel effectiveness.
3. **1-Click WhatsApp Direct Outreach**: Chat with high-priority leads in 1 click without saving phone numbers on your device.
4. **Dynamic Lead Management**: Filter by stage, priority, and source; add new leads through validated forms; and export updated databases to audit-ready Excel (`.xlsx`) workbooks.
5. **Universal File Import**: Upload any raw CSV or Excel sheet to instantly analyze existing lead databases.

## 💻 Local Installation & Setup

```bash
# 1. Clone this repository
git clone https://github.com/Onkarhande96/leadflow-sales-crm-app.git

# 2. Navigate to directory
cd leadflow-sales-crm-app

# 3. Install required packages
pip install -r requirements.txt

# 4. Launch the application
streamlit run app.py
```

The application will automatically start on `http://localhost:8501`.
